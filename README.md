# 🩺 ProjetoDNC - Healtz

Sistema web desenvolvido para otimizar o processo de **check-in de pacientes** em ambientes hospitalares e clínicas, com foco em **usabilidade, simplicidade e segurança**.

---

## 📌 Descrição

Perante as solicitações da empresa, foi idealizado um sistema intuitivo e acessível, capaz de atender usuários com pouco domínio tecnológico. O projeto visa proporcionar **facilidade no manuseio** e **clareza nas informações**, mantendo o usuário informado sobre cada etapa do processo.

---

## 🚀 Tecnologias Utilizadas

- Node.js  
- Express  
- API Google Sheets (como banco de dados)  
- MongoDB (suporte adicional)  
- HTML, CSS e JavaScript (puro)  
- Vercel (hospedagem)

---

## ✅ Funcionalidades

1. Tela de boas-vindas
2. Formulário de cadastro de paciente
3. Check-in online
4. Confirmação de informações
5. Exibição de data/hora e plano de saúde
6. Tela de espera para acompanhamento

---

## 🛠️ Como executar localmente

### Pré-requisitos:

- Node.js instalado
- Conta Google com acesso à API Google Sheets
- Variáveis de ambiente `.env` configuradas com a chave da planilha e credenciais da API

### Passos:

```bash
# Clone o repositório
git clone https://github.com/cristophermlima/ProjetoDNC-Healtz.git

# Acesse a pasta
cd ProjetoDNC-Healtz/backend

# Instale as dependências
npm install

# Inicie o servidor
node index.js

# Acesse no navegador
http://localhost:3000
